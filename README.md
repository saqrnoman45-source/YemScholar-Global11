# NexPath - YemScholar Global

منصة تعليمية ذكية لطلاب اليمن والعالم العربي.

## المميزات

- 📚 دورات تعليمية
- 🌍 منح دراسية
- 🔬 أبحاث علمية
- 🧠 اختبارات قدرات ومهارات
- 🤖 مساعد ذكاء اصطناعي
- 📄 تلخيص PDF
- 🎥 تلخيص الفيديوهات
- 👨‍🏫 نظام طلاب / معلمين / إدارة

## التقنيات المستخدمة

- React
- Vite
- Tailwind CSS
- Supabase (لاحقًا)
- Vercel Deployment

## الهدف

بناء أقوى منصة تعليمية وبحثية في اليمن والعالم العربي.
